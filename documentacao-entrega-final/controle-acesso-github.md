# Compartilhamento e Controle de Acesso com GitHub

## Objetivo

Documentar como o GitHub foi utilizado para versionamento, compartilhamento e controle de acesso do PortfolioHUB.

## Repositorio

O projeto foi armazenado em um repositorio publico no GitHub, permitindo acesso ao codigo e aos arquivos de documentacao.

## Controle de Versao

O controle de versao foi realizado por meio de commits, registrando as alteracoes feitas durante a evolucao do projeto.

## Compartilhamento

O repositorio foi compartilhado por meio do link publico:

```txt
https://github.com/kaubh08/portfolio-academico
```

O PortfolioHUB tambem foi publicado com GitHub Pages:

```txt
https://kaubh08.github.io/portfolio-academico/
```

## Controle de Acesso

- O repositorio foi mantido publico para fins academicos e avaliacao.
- As alteracoes sao feitas pelo usuario responsavel.
- Nao foram incluidos dados sensiveis no projeto.
- O GitHub Pages publica apenas os arquivos necessarios da pasta `docs`.

## Resultado

O GitHub centraliza o codigo, registra a evolucao do projeto e permite o compartilhamento publico do PortfolioHUB.

# Gestao de Usuarios e Seguranca

## Objetivo

Documentar as praticas de seguranca e gestao de acesso utilizadas no PortfolioHUB.

## Gestao de Usuarios

O repositório foi mantido sob controle do usuario responsavel pelo projeto, evitando acesso indevido de terceiros.

## Praticas de Seguranca

- Repositorio publico apenas para visualizacao e avaliacao.
- Controle de alteracoes realizado por commits no GitHub.
- Evitar inclusao de senhas, tokens ou dados sensiveis no repositorio.
- Uso de README e documentacao para orientar o uso correto do projeto.
- Revisao dos arquivos antes do envio para o GitHub.

## Boas Praticas Aplicadas

- Separacao dos projetos por pastas.
- Documentacao dos arquivos principais.
- Publicacao apenas de arquivos necessarios para o GitHub Pages.
- Verificacao dos links publicados.

## Resultado

As praticas adotadas ajudam a manter o projeto organizado, acessivel e seguro para uso academico e demonstracao profissional.

# Portfólio Acadêmico

## Objetivo

Este repositório foi criado para armazenar projetos acadêmicos e pessoais de forma organizada e versionada, utilizando Git e GitHub.

A proposta é compor um perfil profissional, aplicando práticas de versionamento, documentação, colaboração e compartilhamento de código.

## Estrutura do Repositório

O repositório está organizado da seguinte forma:

- `projetos-academicos/`: projetos desenvolvidos durante a graduação.
- `projetos-pessoais/`: projetos criados para estudo, prática e desenvolvimento pessoal.
- `documentacao/`: materiais de apoio, anotações e boas práticas sobre Git, GitHub e desenvolvimento de software.

## Projeto Inicial

O projeto inicial consiste em uma página web simples desenvolvida com HTML e CSS.

Localização do projeto:

```txt
projetos-academicos/pagina-web-v1/
```

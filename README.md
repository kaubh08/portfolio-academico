# PortfolioHUB

Portfolio academico e pessoal desenvolvido para organizar projetos, documentacao tecnica e etapas de implantacao utilizando Git, GitHub e GitHub Pages.

## Sobre o projeto

O PortfolioHUB foi criado como uma plataforma centralizada para apresentar projetos academicos, projetos pessoais e registros de aprendizagem em Engenharia de Software.

A proposta do repositorio e demonstrar organizacao, versionamento, documentacao, publicacao web e boas praticas de compartilhamento de codigo.

## Entrega final: Implantacao PortfolioHUB + Gemini

A entrega final adiciona documentacao sobre o processo de implantacao do PortfolioHUB, incluindo planejamento, seguranca, controle de acesso, testes e apresentacao.

Documentos adicionados:

- `plano-implantacao.md`: plano e etapas da implantacao.
- `uso-gemini.md`: registro do uso do Google Gemini como apoio.
- `seguranca-e-usuarios.md`: praticas de seguranca e gestao de acesso.
- `controle-acesso-github.md`: compartilhamento, versionamento e controle de acesso no GitHub.
- `checklist-testes.md`: validacao dos links e preparacao para uso real.
- `apresentacao-final.md`: roteiro da apresentacao final.

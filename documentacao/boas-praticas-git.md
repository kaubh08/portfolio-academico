# Boas Práticas com Git e GitHub

## Organização do Repositório

- Criar pastas separadas para cada tipo de projeto.
- Manter nomes de arquivos claros e objetivos.
- Utilizar README.md para documentar o repositório e os projetos.

## Commits

- Fazer commits frequentes.
- Usar mensagens claras e descritivas.
- Separar alterações por funcionalidade.

## Versionamento

- Utilizar tags para marcar versões importantes.
- A primeira versão do projeto será identificada como `v1.0`.

## Compartilhamento

- Manter o repositório público quando o objetivo for portfólio.
- Compartilhar o link do GitHub no LinkedIn e em currículos.
